HTTP POST
URL: http://localhost:8080/api/events
Input-Type: RequestBody
Input: eventName (string), eventDate (LocalDate, YYYY-MM-DD), venue (string), eventType (string)
Response: EventResponse { id (long), eventName (string), eventDate (LocalDate), venue (string), eventType (string), organizerId (long) }
Desc: Create a new event for the current organizer.
Sample-Request: {"eventName":"Spring Gala","eventDate":"2026-04-15","venue":"Grand Hall","eventType":"Conference"}
Sample-Response: {"id":101,"eventName":"Spring Gala","eventDate":"2026-04-15","venue":"Grand Hall","eventType":"Conference","organizerId":1}
